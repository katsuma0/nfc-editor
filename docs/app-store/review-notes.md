# Notes for App Review

Paste into the Notes field under App Review Information.

NFC Editor needs a physical NFC tag to test. Any NTAG213, NTAG215 or NTAG216 sticker works, the kind sold in packs of ten. There is no login and no server.

Read tab: tap Scan tag and hold the tag to the top edge of the iPhone. The details screen lists the chip, serial number, memory and records.

Write tab: tap Add a record, pick URL, type one, tap Write, hold the tag.

Tools tab: each tool explains itself at the top of its screen. Lock tag is permanent and sits behind a confirmation switch and a dialog.

The app uses NEHotspotConfiguration only when the user taps Join on a Wi-Fi record read from a tag. It never joins a network on its own.
