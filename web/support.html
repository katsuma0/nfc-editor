NFC Editor support

Something not working, or a tag the app doesn't understand? Open an issue with the chip name from the Read screen and what you tried. I read every one.

The scan sheet never finds the tag

Hold the tag flat against the top edge of the iPhone, near the camera, and keep it still for a second. Phone cases with metal or a magnetic wallet block NFC. It needs iOS 17 or later, so an iPhone XS, XR, SE (2nd generation) or newer.

It says the tag is not set up for writing

Blank tags sometimes ship empty. Use Format tag in Tools, then write again. A DESFire card needs an NDEF application instead: tap Show advanced tools, then DESFire card.

It says the tag is password protected

Someone set a password on it. Use Password in Tools with the right password to remove it. Without the password the tag can be read but not changed.

Can it read MIFARE Classic, bank cards or passports?

No. iOS does not let apps read MIFARE Classic data, and reading other people's payment cards and documents is not what this app is for.

I locked a tag by mistake

Locking is permanent on every chip. Nothing can undo it, which is why the app asks twice.
